# Minh Chứng Đóng Gói Và Triển Khai Sản Phẩm (Release Packaging)

* **Sản phẩm đóng gói:** Bản phát hành Web/PWA hoàn chỉnh (budget/build/web/) và gói nén phát hành Cashew-Web-Release.zip.
* **Trạng thái biên dịch:** `flutter build web --release` thành công 100% với kỹ thuật AOT, Tree-shaking và tối ưu hóa tài nguyên.
* **Khởi chạy ứng dụng:** Ứng dụng đã khởi chạy và kiểm thử thực tế trên trình duyệt Google Chrome với đầy đủ các tính năng tùy chỉnh giao diện và nghiệp vụ.

## Bộ ảnh minh chứng hoàn chỉnh:
* `screenshots/crud/`: 5 ảnh kiểm thử chức năng CRUD (Thêm, Sửa, Xóa chi tiêu, Quản lý danh mục & ngân sách, Biểu đồ thống kê số dư).
* `screenshots/customization/`: 5 ảnh minh chứng tùy chỉnh giao diện Theme Emerald, Banner cài đặt, Màn hình About nhóm đồ án, Tiền tệ mặc định VNĐ, Danh mục chi tiêu sinh viên.
